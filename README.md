# 天津神・国津神 図鑑

『古事記』『日本書紀』にあらわれる神々 **62柱** を、系譜・神話・ご利益・祀られる社から引ける図鑑アプリ。

## 使い方

```
apps/kamigami-zukan/index.html をブラウザで開く
```

ビルド不要・依存パッケージなし。`file://` で直接開いても動作する。
サーバに置く場合はディレクトリごと静的ホスティングに上げるだけでよい。

## 機能

| 機能 | 内容 |
|---|---|
| 全文検索 | 神名・かな・ローマ字・別名・解説・神社名・ご利益を横断。カタカナ／ひらがなを相互に吸収し、空白区切りはAND検索 |
| 絞り込み | 区分（別天津神／神世七代／天津神／国津神）・ご利益・神話の3軸。組み合わせ可能で、0件になる選択肢は自動的に薄く表示 |
| 並び替え | 記紀の登場順／五十音順／区分順 |
| 詳細表示 | 別名・親神・配偶・子神・神話・ご利益・主な社・典拠・属性・こぼれ話 |
| 系譜たどり | 詳細内の親神・配偶・子神をクリックすると、その神へ直接ジャンプ |
| 今日の一柱 | 表示中の対象からランダムに1柱を開く |
| ディープリンク | `index.html#okuninushi` のように神ごとのURLで直接開ける |
| 配色 | ライト／ダーク。OS設定に追従し、手動切り替えは localStorage に保持 |
| キーボード | `/` 検索へ移動、`←` `→` 前後の神、`Esc` 閉じる |

## 構成

```
apps/kamigami-zukan/
├── index.html          画面構造
├── assets/styles.css   和の伝統色（墨・生成り・朱・金・藍）を基調とした配色
├── assets/app.js       検索・絞り込み・詳細表示（依存なし・約380行）
└── data/deities.js     神格データ 62柱
```

## データを増やす・直す

`data/deities.js` の配列に追記するだけでよい。UI側の修正は不要で、
ご利益・神話のフィルタ項目も出現頻度から自動生成される。

```js
{
  id: "unique_id",          // 半角英数。ディープリンクと系譜参照に使う
  name: "神名",
  kana: "カナ",
  romaji: "Romaji",
  group: "天津神",           // 別天津神 / 神世七代 / 天津神 / 国津神
  aliases: ["別名"],
  epithet: "一行で言うとどんな神か",
  tags: ["属性"],
  benefits: ["ご利益"],
  parents: [], spouse: [], children: [],   // 他エントリの id を書く
  myths: ["登場する神話"],
  shrines: ["主な神社（所在地）"],
  sources: ["典拠"],
  description: "解説",
  trivia: "こぼれ話"
}
```

### 整合性チェック

系譜の参照先が存在するか、idが重複していないかを確認する。

```bash
node -e "
const d=require('./data/deities.js');
const ids=new Set(d.map(x=>x.id)); const bad=new Set();
d.forEach(x=>[...x.parents,...x.spouse,...x.children].forEach(r=>{if(!ids.has(r))bad.add(r)}));
const dup=d.map(x=>x.id).filter((v,i,a)=>a.indexOf(v)!==i);
console.log('柱数:',d.length,'| 参照切れ:',[...bad].join(',')||'なし','| id重複:',dup.join(',')||'なし');
"
```

## 典拠と表記について

- 神名の表記は原則『古事記』に従い、『日本書紀』などの異表記は各項の「別名」に併記した。
- 区分は記紀の文脈にもとづく一般的な分類。須佐之男命のように複数の性格をあわせ持つ神もあり、
  分類はあくまで検索の便宜のためのものとして扱っている。
- 記述は記紀および各社の社伝の範囲にとどめ、学説の対立がある事項は「〜とする説がある」と明示した。
