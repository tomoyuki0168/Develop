# 天津神・国津神 図鑑

**神様の名前を入れると、別名・ご利益・主な神社が引ける**図鑑アプリ。
『古事記』『日本書紀』ほかにあらわれる神々 **127柱** を収録。**日本語・English・简体中文・繁體中文・한국어 対応。**

Developed by Tomoyuki☯️

## 使い方

```
apps/kamigami-zukan/index.html をブラウザで開く
```

ビルド不要・依存パッケージなし・外部通信なし。`file://` で直接開いても動作する。
サーバに置く場合はディレクトリごと静的ホスティングに上げるだけでよい。

## 名前で引く

入力欄に神名を打つと、候補が下に出る。選べばその神の頁が開く。

| 入力例 | 出るもの |
|---|---|
| `おおくにぬし` / `オオクニヌシ` / `大国主` | 大国主神 |
| `だいこく` | 大国主神（通称: だいこく） |
| `えびす` | 事代主神・蛭子神（通称で両方に当たる） |
| `いなり` | 宇迦之御魂神（通称: いなり） |
| `Amaterasu` | 天照大御神（ローマ字表記） |
| `出雲大社` | その社に祀られる神 8柱 |
| `縁結び` | ご利益が縁結びの神 31柱 |

- **かなは相互変換**する。ひらがな・カタカナどちらで打っても同じ結果になる。
- **正式名でなくても引ける**。「だいこく」「べんてん」「こんぴら」「おとりさま」などの
  通称は `data/deities.js` 末尾の `KEYWORDS` 表で正式な神名に結びつけてある。
- 名前以外で当たった場合は、カードに **どの項目で一致したか**（`別名「大黒天」に一致` など）が出る。
- 空白区切りは AND 検索。`海 縁結び` で両方に当てはまる神だけが残る。

## 多言語対応

右上で **日本語 / English / 简体中文 / 繁體中文 / 한국어** を切り替えられる。
来日した外国人が神社の前で引けることを想定している。

各言語で、次のすべてを訳してある。

| 対象 | 分量 |
|---|---|
| 画面のことば | 66項目 |
| 神格の解説・こぼれ話 | **127柱すべて** |
| ご利益・神話・属性・典拠 | 340語（その言語のまま絞り込める） |

**神名と神社名の扱いは言語ごとに変える。**

| 言語 | 神名の見出し | 神社名 |
|---|---|---|
| English | ローマ字（`Ōkuninushi`） | ローマ字 + 所在地（289社） |
| 한국어 | ハングル音写（`오쿠니누시`） | ローマ字表記を借用 |
| 简体中文 / 繁體中文 | 漢字のまま | 漢字のまま |

漢字圏の読者には原表記がそのまま読めるので、変換せず残す。
英語・韓国語では見出しをローマ字／ハングルにしたうえで、**漢字とかなを必ず併記する。**
地図アプリに入力したり、現地の案内表示と突き合わせたりするには漢字が要るためである。

### 言語の決まり方

1. URLの `?lang=en` `?lang=zh-Hans` `?lang=zh-Hant` `?lang=ko` `?lang=ja`
2. 前回の選択（localStorage に保存）
3. ブラウザの言語設定 — 日本語なら日本語、それ以外は英語
4. 既定は日本語

### 検索は言語をまたぐ

表示言語が何であれ、日本語でも英語でも自言語でも引ける。

| 入力 | 結果 |
|---|---|
| `Okuninushi` / `okuninushi` | 大国主神（長音記号の有無を問わない） |
| `matchmaking`（韓国語表示のまま） | ご利益が縁結びの神 31柱 |
| `인연 맺기` / `结缘` / `結緣` | 同上 |
| `いなり`（何語表示でも） | 宇迦之御魂神 |
| `大國主` / `大国主` | どちらでも大国主神 |
| `木花之佐久夜毘賣` | 木花之佐久夜毘売 |

**新字体・簡体字・繁体字は同じものとして扱う。** `國`＝`国`、`毘賣`＝`毘売`、
`豐宇氣`＝`豊宇気` のように畳んでから照合する。検索語と検索対象の両方に
同じ変換をかけるので、取りこぼしは起きない。対応表は
`tools/make-variants.py` が神名・神社名・語彙に実際に現れる字から生成した。

## 引ける項目

各神について次を収録している。

| 項目 | 内容 |
|---|---|
| 神名 / かな / ローマ字 | 表記は原則『古事記』に従う |
| **別名** | 『日本書紀』の異表記、習合した仏神、通称（全242件） |
| **ご利益** | 113種を分類。ご利益からの逆引きも可能 |
| **主な神社** | 全国289社。社名からの逆引きも可能 |
| 系譜 | 親神・配偶・子神。クリックでその神へジャンプ |
| 神話 | 登場する神話51種。神話からの逆引きも可能 |
| 典拠 | どの文献の記述にもとづくか |
| 解説・こぼれ話 | 何をした神か、なぜ祀られるか |

## 機能

| 機能 | 内容 |
|---|---|
| 神名サジェスト | 入力に応じて候補を表示。`↑` `↓` で選び `Enter` で直接開く |
| 全文検索 | 神名・かな・ローマ字・別名・通称・ご利益・神社・神話・解説を横断 |
| 絞り込み | 区分（別天津神／神世七代／天津神／国津神）・ご利益・神話の3軸。0件になる選択肢は自動的に減光 |
| 表示形式 | **カード** と **一覧表**（神名・区分・別名・ご利益・主な神社の5列）を切り替え |
| 並び替え | 記紀の登場順／五十音順／区分順 |
| 系譜たどり | 詳細内の親神・配偶・子神をクリックでジャンプ。逆参照は自動生成される |
| 今日の一柱 | 表示中の対象からランダムに1柱を開く |
| ディープリンク | `index.html#okuninushi` のように神ごとのURLで直接開ける |
| 配色 | ライト／ダーク。OS設定に追従し、手動切り替えは localStorage に保持 |
| キーボード | `/` 検索へ移動、`↑` `↓` 候補選択、`Enter` 決定、`←` `→` 前後の神、`Esc` 閉じる |

## 収録範囲

| 区分 | 柱数 | 内容 |
|---|---|---|
| 別天津神 | 5 | 天地開闢の直後に成った、姿を持たない根源の神々 |
| 神世七代 | 8 | 国土の形成を担った七代。伊邪那岐・伊邪那美を含む |
| 天津神 | 55 | 高天原の神、およびそこから地上に降った神々 |
| 国津神 | 59 | 葦原中国に土着する神々。山・海・草木・穀物の神を含む |
| **計** | **127** | |

典拠は『古事記』『日本書紀』『出雲国風土記』『古語拾遺』『大祓詞』および各社の社伝。
菅原道真・応神天皇のように**人が神として祀られた「人神」は収めていない**（範囲を神代〜神武東征に限った）。

区分は記紀の文脈にもとづく一般的な分類であり、須佐之男命のように複数の性格をあわせ持つ神もいる。
学説の対立がある事項は「〜とする説がある」と明示した。

## データを増やす・直す

`data/deities.js` の配列に追記するだけでよい。UI側の修正は不要で、
ご利益・神話のフィルタ項目も出現頻度から自動生成される。

```js
{
  id: "unique_id",          // 半角英数。ディープリンクと系譜参照に使う
  name: "神名", kana: "カナ", romaji: "Romaji",
  group: "天津神",           // 別天津神 / 神世七代 / 天津神 / 国津神
  aliases: ["別名"],
  epithet: "一行で言うとどんな神か",
  tags: ["属性"], benefits: ["ご利益"],
  parents: [], spouse: [], children: [],   // 他エントリの id を書く（片方向でよい）
  myths: ["登場する神話"],
  shrines: ["主な神社（所在地）"],
  sources: ["典拠"],
  description: "解説", trivia: "こぼれ話"
}
```

**系譜は片方向だけ書けばよい。** 子に親を書けば、親の側の子リストは起動時に自動で張られる。

通称で引かせたい神は、ファイル末尾の `KEYWORDS` に追記する。

```js
var KEYWORDS = {
  ukanomitama: ["いなり", "おいなりさん", "稲荷"],
  // ...
};
```

### 整合性チェック

系譜の参照先が存在するか、idが重複していないかを確認する。

```bash
node -e "
const d=require('./data/deities.js');
const ids=new Set(d.map(x=>x.id)); const bad=new Set();
d.forEach(x=>[...x.parents,...x.spouse,...x.children].forEach(r=>{if(!ids.has(r))bad.add(r)}));
const dup=d.map(x=>x.id).filter((v,i,a)=>a.indexOf(v)!==i);
console.log('柱数:',d.length,'| 参照切れ:',[...bad].join(',')||'なし','| id重複:',dup.join(',')||'なし');
"
```

## 言語を追加する

`data/i18n/en.js` を複製し、`window.I18N.<コード>` として定義する。
`index.html` に `<script>` を1行、言語の `<option>` を1つ、`build.js` の `langs` に
コードを1つ足せば増える。アプリ側の修正は要らない。

- 訳が欠けている項目は自動的に日本語のまま表示される
- `name` を省くと漢字表記がそのまま見出しになる（中国語版がこの方式）
- `placesFrom: "en"` を指定すると、神社名は英語版の表記を借りる（韓国語版がこの方式）

### 繁体版の再生成

`data/i18n/zh-Hans.js` を直したら、繁体版を作り直す。

```bash
python3 tools/make-zh-hant.py
```

機械変換が誤る語（沖／衝、製棺、東征など）はスクリプト内の `FIXES` `POST_FIXES` で
個別に補正している。変換漏れがあればビルドを失敗させる検査つき。
