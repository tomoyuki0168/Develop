# 手相鑑定所

手のひらを撮ると、写真から手の輪郭と三大線（生命線・知能線・感情線）を自動で検出し、
線の形を実測して鑑定書を出すアプリ。娯楽としての手相の読み解き。

- 公開URL: https://tomoyuki0168.github.io/Develop/tesou/
- 実体は `index.html` 一枚。ビルド不要・依存なし・外部通信なし。
- 写真は端末内の canvas だけで処理し、どこにも送信しない。
- 写真が使えない環境では、線を手で合わせても同じ鑑定が出る。

開発元は本社リポジトリ（`products/palm-reading/`）。ここに置いてあるのは、
カメラを使うために https で配信する必要があるため。
